Recipe recommendation: Allergy Based is a python programmed system where it recommends recipes based on the users inputted allergies.

# How it works and features
- The Recipe recommender uses a very code that changes the result based on the users input. 
- The user is asked a few sets of question then are four recipes they can choose from.
- Once the result has run, it is able to give surface level information like, its duration and its key ingredients.
- It runs mainly on If statements and dictionaries.
